# Rockabilly Roasting — Website UI Kit

🚩 **No existing website or codebase was provided.** This kit is a **hi-fi proposal** of what a Rockabilly Roasting marketing site could look like, built from the brand mark, the candle illustration, and the tone described in the main README. If a real site exists, please share it and this kit will be rebuilt against the real thing.

## Files

- `index.html` — the kit entry point. Full marketing homepage composed from the components below.
- `Header.jsx` — top navigation with shield mark + nav + cart
- `Hero.jsx` — hero section with big slab headline + candle illustration
- `Marquee.jsx` — scrolling marquee ribbon
- `Coffees.jsx` — "This Week's Roast" product grid
- `Story.jsx` — about section with script flourish + quote
- `MenuBoard.jsx` — cafe menu board, dark
- `Visit.jsx` — visit / hours / address card
- `Footer.jsx` — footer with badge + social
- `Primitives.jsx` — shared Button, Chip, Eyebrow

## Components covered

Header, hero, marquee, product card grid, editorial story block, dark menu board, contact card, footer, buttons, chips, tags.
